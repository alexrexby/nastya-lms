# План разработки платформы для репетитора по химии (Nastya LMS)

## Архитектура и первые принципы
- **Единая экосистема:** публичный контент (SEO, статьи, открытые тесты) + закрытый личный кабинет (группы, видео, ДЗ).
- **Разделение программы и когорты:** 
  - `Lesson` — мастер-каркас (теория, банк тестов, критерии ДЗ).
  - `GroupLesson` — инстанс урока в группе (индивидуальное видео конкретного занятия, дата, заметки группы).
- **Химическая специфика:**
  - KaTeX для химических формул и уравнений реакций ($\text{H}_2\text{SO}_4$, $\text{Cu}^{2+} + 2\text{OH}^- \rightarrow \text{Cu(OH)}_2\downarrow$).
  - Специализированные типы тестов ЕГЭ/ОГЭ: выбор 2 из 5, соответствие (матрица 4x4/4x5), расчетные задачи с вводом числа и погрешностью округления.
  - Мгновенный разбор с пояснением уравнений и признаков реакций (цвет осадка, газ).
  - Сдача 2-й части через фото рукописных тетрадей.
- **Стек:** Next.js 15/16 (App Router), React 19, TypeScript, Tailwind CSS, Lucide Icons, Prisma ORM (SQLite для мгновенного развертывания без внешней БД, легко переключается на PostgreSQL).

## Этапы реализации

### Этап 1: Инициализация проекта и стек
- Инициализация Next.js с TypeScript, Tailwind CSS, ESLint, App Router.
- Настройка Prisma схемы базы данных:
  - `User` (роли: `STUDENT`, `TEACHER`, `ADMIN`).
  - `Article` (статьи/теория).
  - `Course`, `Module`, `Lesson` (мастер-программа).
  - `Group`, `GroupEnrollment`, `GroupLesson` (когорты и индивидуальные видео уроков).
  - `Question`, `QuizAttempt` (тесты с поддержкой 4 типов вопросов).
  - `Submission` (сдача ДЗ с фото и рецензией учителя).
- Настройка mock/seed данных с реальными темами и тестами по химии (ЕГЭ).

### Этап 2: Химический движок и компоненты рендеринга
- Компонент `ChemistryFormula` / `KaTeX` рендерер.
- Компоненты интерактивного тестирования:
  - `SingleChoiceQuestion`
  - `MultipleChoiceQuestion` (выбор 2 из 5)
  - `MatchingQuestion` (соответствие вещество $\leftrightarrow$ реагент)
  - `NumberInputQuestion` (расчетная задача с округлением)
  - `QuestionFeedback` (блок мгновенного разбора с уравнениями)

### Этап 3: Публичная часть (Сайт как у Степенина)
- Главная страница репетитора: оффер, форматы обучения (мини-группы, индивидуально), отзывы, призыв к действию, ссылка на открытый тренажер.
- Раздел статей (`/articles` и `/articles/[slug]`): конспекты, формулы, встроенный проверочный тест в конце статьи.
- Открытый тренажер тестов (`/tests`): выбор темы (Строение атома, Неорганика, Органика, Задачи), прохождение теста без обязательной регистрации, показ результатов.
- Страница записи / контакты.

### Этап 4: Личный кабинет ученика (`/dashboard`)
- Список моих групп и расписание занятий.
- Страница урока группы (`/dashboard/lessons/[groupLessonId]`):
  - Видеоплеер с записью занятия именно этой группы.
  - Конспект и материалы мастер-урока.
  - Интерактивный тест к уроку с подсчетом баллов.
  - Блок сдачи ДЗ (текст + загрузка фото тетради).

### Этап 5: Панель управления репетитора (`/admin`)
- Управление курсами и мастер-каркасом (создание тем, добавление тестов).
- Управление группами:
  - Создание групп и добавление учеников.
  - **Загрузка видео к уроку конкретной группы** (то, чего не хватало в Tutorclass).
- Проверка сданных домашних заданий:
  - Просмотр фото тетради.
  - Выставление баллов и текстовый комментарий ученику.
- Управление статьями.

### Этап 6: Тестирование, верификация и запуск
- Проверка всех сценариев: прохождение тестов всех 4 типов, загрузка видео к группам, прикрепление ДЗ, переключение ролей.
- Прогон билда `npm run build`.
