# ChemClass (Nastya LMS) 🧪

Авторская образовательная веб-платформа и сайт для репетитора по химии (подготовка к ЕГЭ и ОГЭ), вдохновленная [stepenin.ru](https://stepenin.ru/).

## Ключевые возможности

### 1. Объединение сайта и закрытой LMS (Без швов)
- **Открытый сайт для привлечения (SEO):** статьи, качественные реакции, шпаргалки с химическими формулами ($\text{H}_2\text{SO}_4$, $\text{Cu(OH)}_2\downarrow$), таблица осадков.
- **Интерактивный тренажёр заданий ЕГЭ:**
  - Одиночный и множественный выбор (выберите 2 из 5).
  - Задания на соответствие (матрица вещество $\leftrightarrow$ признак реакции / реагент).
  - Расчетные задачи (линия 26) с вводом числа и автоматической проверкой округления.
  - **Мгновенный разбор (как у Степенина):** сразу после ответа показываются уравнения реакций, цвета осадков и признаки.
- **Личный кабинет ученика и учительская:** закрытые материалы, расписание, сдача ДЗ.

### 2. Решение главной боли Tutorclass: «Каркас курса + Видео для каждой группы»
- **Каркас программы (Мастер-силлабус):** программа курса, темы, конспекты, банк вопросов и домашнее задание создаются в одном экземпляре.
- **Индивидуальные видеозаписи групп:** для каждой мини-группы (например, «Группа А: Пн/Чт 16:00» и «Группа Б: Вт/Пт 18:30») репетитор прикрепляет ссылку на запись живого занятия **именно этой группы**.
- **Результат:** нет необходимости дублировать курс для каждой группы или путать учеников общими записями.

### 3. Сдача 2-й части (цепочки реакций и 34-е задачи)
- Ученик прикрепляет фото страниц тетради прямо со смартфона.
- Репетитор в учительской видит работы, оставляет рецензию и выставляет первичные баллы.

## Стек технологий
- **Фреймворк:** Next.js 15 (App Router, Server & Client Components)
- **Язык:** TypeScript
- **Стилизация:** Tailwind CSS
- **Химический рендерер:** KaTeX (поддержка формул, индексов, стрелок осадков и газов)
- **Иконки:** Lucide React
- **База данных:** Prisma ORM

## Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка и запуск продакшн
npm run build
npm start
```

Сервер доступен по адресу: [http://localhost:3000](http://localhost:3000)

## Маршруты приложения
- `/` — Главная страница с оффером, преимуществами и пробным тренажером.
- `/articles` — Каталог статей и конспектов по химии.
- `/articles/[slug]` — Детальная статья с формулами и встроенным проверочным тестом.
- `/tests` — Открытый интерактивный тренажер заданий ЕГЭ.
- `/courses` — Витрина курсов и расписание действующих мини-групп.
- `/dashboard` — Личный кабинет ученика (моя группа, уроки).
- `/dashboard/lessons/[id]` — Страница урока с видеозаписью группы, конспектом, тестом и формой сдачи ДЗ.
- `/admin` — Панель управления репетитора (учительская).
- `/admin/groups/[id]` — Модуль привязки видеозаписей к урокам конкретной группы.
